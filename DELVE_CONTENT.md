# Ironsworn: Delve - Conteúdo Disponível

Este documento descreve o conteúdo disponível no pacote `@datasworn/ironsworn-classic-delve` que pode ser integrado ao Iron Oracle.

## 📦 Pacote NPM
- **Nome**: `@datasworn/ironsworn-classic-delve`
- **Versão**: `^0.0.10`
- **Arquivo JSON**: `@datasworn/ironsworn-classic-delve/json/delve.json`

## 🎲 Oráculos (Oracles)

### Character
- **Activity** (d100): 50 resultados - atividades que um NPC ou facção está realizando
- **Disposition** (d100): 12 resultados - tom inicial de um encontro com NPC ou facção

### Combat Event
- **Method** (d100): 50 resultados - métodos de ação em combate
- **Target** (d100): 50 resultados - alvos de ações em combate

### Feature
- **Aspect** (d100): 50 resultados - aspectos de uma localização ou evento
- **Focus** (d100): 50 resultados - foco de uma localização ou evento

### Monstrosity
- **Size** (d100): 6 resultados - tamanho de uma criatura monstruosa
- **Primary Form** (d100): 20 resultados - forma primária da criatura
- **Characteristics** (d100): 30 resultados - características físicas
- **Abilities** (d100): 35 resultados - habilidades especiais

### Moves
- **Find an Opportunity** (d100): 10 resultados - oportunidades encontradas em um site
- **Reveal a Danger** (d100): 12 resultados - perigos revelados
- **Reveal a Danger (alternate)** (d100): 10 resultados - versão alternativa
- **Advance a Threat** (d100): 3 resultados - avanço de uma ameaça
- **Delve the Depths** (tabela compartilhada):

  - Shadow (d100): 5 resultados

### Threat

- **Cursed Site** (d100): 10 resultados
- **Environmental Calamity** (d100): 10 resultados

## 🔗 Estrutura de IDs

Todos os IDs seguem o padrão `delve/...`:
- Oráculos: `delve/oracles/...`
- Moves: `delve/moves/...`
- NPCs: `delve/npcs/...`
- Rarities: `delve/rarities/...`
- Sites: `delve/delve_sites/...`
- Domains: `delve/site_domains/...`
- Themes: `delve/site_themes/...`

## 📝 Notas de Implementação

- O Delve é uma expansão do Ironsworn Classic, então pode ser usado junto com os dados base
- Muitos oráculos têm referências cruzadas com oráculos do Classic (usando `classic/oracles/...`)
- Alguns oráculos têm sugestões de outros oráculos para rolar em conjunto
- O sistema de Sites usa uma combinação de Theme + Domain para gerar conteúdo
- Os Delve Sites pré-definidos incluem tabelas de denizens com frequências

## 🚀 Próximos Passos

Para integrar o Delve ao Iron Oracle:

1. Instalar o pacote: `npm install @datasworn/ironsworn-classic-delve`
2. Importar os dados: `import delveData from '@datasworn/ironsworn-classic-delve/json/delve.json'`
3. Mesclar com os dados do Ironsworn Classic
4. Adicionar suporte para navegação dos oráculos do Delve
5. Implementar traduções para português (se necessário)
6. Adicionar ícones/identificação visual para conteúdo do Delve
